# Growth

## Description
Growth is a habit tracking dashboard that allows users to create and track multiple habits they wish to grow.

## Use Cases
- User wants to see the currently tracked habits
- User wants to check-off a habit they completed today
- User wants to view the current habit streak
- User wants to check the habits list on a previous day
- User wants to create a new account
- User wants to login to an account
- User wants to remove a habit from the list
- User wants to edit the information of a habit
- User wants to reorder the habits list
- User wants to delete account

## Specification
### Tech Stack
Front-end
Angular and Typescript for webpage design

Project is deployed using Docker
